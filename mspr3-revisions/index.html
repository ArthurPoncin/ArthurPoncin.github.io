Fiches de révision : MSPR3 (TPRE601)

Supports de révision pour la soutenance MSPR3 (blocs E6.3/E6.4 : « Mise en production d'une solution à partir des éléments de contextes fournis »). Une fiche par domaine de livrable, structurée comme les fiches des MSPR précédentes : vocabulaire, vue d'ensemble, détails techniques, exemples de code essentiels, questions possibles du jury.

Ces fiches complètent les fiches MSPR1 (ETL, DB, AUTH, API, FRONT) et les fiches MSPR2 (AI-Nutrition, Reco-Fitness, MongoDB, modèle de données, front v2) sans les remplacer. Elles couvrent les 6 dossiers de livrables MSPR3 : conteneurisation et orchestration, observabilité, CI/CD et qualité, sécurité, gestion de projet, application mobile.

Les 7 fiches

  • 1. Déploiement et orchestration Docker Compose · GHCR · bash Démarrage en une commande (bootstrap.sh, 84 s mesurées pour < 10 min exigées), 11 services, 2 réseaux, healthchecks, secrets générés et déchiffrés.
  • 2. Configurations et résilience Overlays Compose · Traefik · pg_dump Les 3 configurations du sujet (complète, offline, performance), overlays traefik/vision/watchtower/gpu, sauvegarde et restauration des 3 bases.
  • 3. Observabilité et supervision Prometheus · Grafana · Loki · Alertmanager 10 cibles scrapées, instrumentation des 4 services dans leur code source, 3 alertes, 4 dashboards provisionnés, logs centralisés, runbook.
  • 4. CI/CD et qualité GitHub Actions · GHCR · Watchtower · SonarCloud 8 chaînes CI, publication conditionnée aux tests, tags traçables (semver, SHA), CD Watchtower, couvertures 92 % / 85 %, indicateurs SonarCloud.
  • 5. Sécurité OWASP Top 10 · RGPD · NIST CSF Analyse par 3 référentiels, durcissement des conteneurs (non-root, no-new-privileges, 127.0.0.1), secrets chiffrés, limites assumées.
  • 6. Gestion de projet agile Agile · Kanban · GitHub Projects 4 sprints A-D, cérémonies allégées, kanban commun de l'organisation whitefoxxyt, gestion des risques, définition du fini.
  • 7. Application mobile Expo 54 · React Native 0.81 · TypeScript 5.9 Client mobile de la plateforme (développé par un autre membre de l'équipe), intégration JWT, conteneurisation du bundler, reste à faire.

Conseils de lecture

  • Première lecture : parcourir la section Vocabulaire et la TL;DR de chaque fiche pour avoir la carte mentale complète MSPR3.
  • Seconde lecture : focus sur les fiches du domaine qu'on est susceptible de présenter (Code essentiel + Questions jury).
  • Veille de soutenance : relire la section Questions probables du jury de chaque fiche.

Structure commune

Chaque fiche suit le même plan que les fiches MSPR1/MSPR2 :

  1. Vocabulaire : 8 à 10 termes techniques non triviaux avec définition simple
  2. TL;DR : résumé en quelques lignes du domaine
  3. Architecture / Stack : technos utilisées et diagrammes
  4. Détails techniques : fonctionnement interne, patterns, choix d'implémentation
  5. Code essentiel à savoir expliquer au jury : 6 à 8 extraits commentés, copiés des dépôts réels
  6. Questions probables du jury : 10 à 12 questions avec réponses préparées

La fiche Gestion de projet remplace les extraits de code par des « éléments concrets à citer au jury ».

Hors scope

Ces fiches couvrent uniquement la MSPR3 (TPRE601). Les microservices et la documentation des MSPR précédentes sont traités dans les fiches MSPR1 et les fiches MSPR2.
