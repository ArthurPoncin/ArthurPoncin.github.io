Fiches de révision — MSPR1 (TPRE501)

Supports de révision pour la soutenance du projet HealthAI Coach. Une fiche par microservice, structurée de la même façon : vocabulaire, vue d'ensemble, détails techniques, exemples de code essentiels, questions possibles du jury.

Ces fiches complètent le dossier technique et les slides de soutenance. Elles sont taillées pour réviser vite et pour pouvoir répondre au jury sur les choix techniques et les points non triviaux.

Les 5 fiches

  • 1. ETL Python 3.12 · pandas · psycopg2 · APScheduler Pipeline d'ingestion / nettoyage / chargement. Idempotence, rejets, observabilité.
  • 2. Base de données PostgreSQL 17 · migrations SQL Schéma, 7 migrations, contraintes UNIQUE NULLS NOT DISTINCT, index GIN.
  • 3. Authentification Bun · Hono · better-auth · Drizzle Auth email/password, sessions, double JWT (RSA plugin + HMAC custom).
  • 4. API métier Spring Boot 4 · Java 21 · Spring Security 9 controllers, filtre JWT HS512 stateless, exception handler global.
  • 5. Dashboard front Vue 3.5 · Pinia 3 · Vite 8 4 vues, guards de routes, bootstrap session post-vérification email.

Conseils de lecture

  • Première lecture — parcourir la section Vocabulaire et la Vue d'ensemble de chaque fiche pour avoir la carte mentale complète du projet.
  • Seconde lecture — lire la section Code essentiel à savoir expliquer au jury de la fiche correspondant au service qu'on est susceptible de présenter.
  • Veille de soutenance — relire la section Questions possibles du jury de chaque fiche.

Structure commune

Chaque fiche suit le même plan :

  1. Vocabulaire — 5 à 10 termes techniques non triviaux avec définition simple
  2. TL;DR — résumé en quelques lignes du rôle du service
  3. Stack / Architecture — technos utilisées et diagramme si pertinent
  4. Détails techniques — fonctionnement interne, patterns, choix d'implémentation
  5. Code essentiel à savoir expliquer au jury — 6 à 8 extraits commentés
  6. Questions possibles du jury — 12 questions avec réponses préparées

Hors scope

Ces fiches couvrent uniquement la MSPR1. Les microservices de la MSPR2 (MSPR-AI-Nutrition, MSPR-Reco-Fitness, MSPR-MongoDB) ne sont pas traités ici.
