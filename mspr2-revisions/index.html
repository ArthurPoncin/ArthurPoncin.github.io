Fiches de révision — MSPR2 (TPRE502)

Supports de révision pour la soutenance MSPR2. Une fiche par service ajouté par la MSPR2, structurée comme les fiches MSPR1 : vocabulaire, vue d'ensemble, détails techniques, exemples de code essentiels, questions possibles du jury.

Ces fiches complètent les fiches MSPR1 (ETL, DB, AUTH, API, FRONT) sans les remplacer. Elles couvrent les 11 livrables MSPR2 mappés aux 12 compétences de la grille de jury (Bloc 2 : « Développer un modèle prédictif d'une solution I.A »).

Les 5 fiches

  • 1. AI-Nutrition FastAPI · HuggingFace · Mistral · Ollama Vision Food-101 (ViT, F1 0.91), LLM multi-provider (Mistral primaire ~4 s, Ollama fallback), DeCRIM-light + few-shot.
  • 2. Reco-Fitness FastAPI · MongoDB · scikit-learn · motor Scoring hybride rule-based + RandomForest (F1 0.978), freemium graduel free / premium / premium+, feedback adaptatif.
  • 3. MongoDB MongoDB 7 · Mongo shell Init des 3 collections fitness + index composés. Image GHCR, idempotence, intégration compose racine.
  • 4. Modèle de données MSPR2 PostgreSQL 17 · MongoDB · JSONB 8 migrations V8-V15, 3 nouvelles tables AI-Nutrition, pivot user_id cross-base (nanoID better-auth), photos base64.
  • 5. Frontend MSPR2 Vue 3.5 · Pinia 3 · Chart.js · Vite 8 11 vues utilisateur, design system éditorial, accessibilité WCAG AA (Lighthouse 100/100), sélecteur LLM, gestion robuste des APIs.

Conseils de lecture

  • Première lecture — parcourir la section Vocabulaire et la TL;DR de chaque fiche pour avoir la carte mentale complète MSPR2.
  • Seconde lecture — focus sur les fiches du service qu'on est susceptible de présenter (Code essentiel + Questions jury).
  • Veille de soutenance — relire la section Questions probables du jury de chaque fiche.

Structure commune

Chaque fiche suit le même plan que les fiches MSPR1 :

  1. Vocabulaire — 5 à 10 termes techniques non triviaux avec définition simple
  2. TL;DR — résumé en quelques lignes du rôle du service
  3. Stack / Architecture — technos utilisées et diagramme si pertinent
  4. Détails techniques — fonctionnement interne, patterns, choix d'implémentation
  5. Code essentiel à savoir expliquer au jury — 6 à 8 extraits commentés
  6. Questions possibles du jury — 10 à 12 questions avec réponses préparées

Hors scope

Ces fiches couvrent uniquement la MSPR2. Les microservices et la documentation MSPR1 (ETL, DB, AUTH, API, FRONT v1) sont traités dans les fiches MSPR1.
